Proyek ini merupakan halaman portofolio sederhana yang dibangun sebagai bagian dari asesmen Front End Developer Magang Hub KEMAS Batch 2. Halaman ini menampilkan informasi pribadi, deskripsi singkat, keterampilan, dan tautan sosial menggunakan desain modern.

## Fitur Utama

Desain modern & responsif

Profil developer (nama, deskripsi, keahlian)

Mode tampilan bersih & profesional
